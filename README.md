# PigeonLearningDynamics

Homing-pigeon route-learning analysis across two GPS datasets.

- **`main`** branch (this one): the **data deposit** — see [`DATASETS.md`](DATASETS.md).
- **`hv`** branch: analysis code and the **interactive viewer**
  (`bird_route_development.html`) — single-bird route-development tracks,
  population heatmaps, multiple basemaps, and ERA5 weather/cloud overlays.

## Datasets
1. **Flack et al. (2014)** — multi-route homing (included, ~22 MB).
2. **Valentini et al. (2021)** — collective exploration (download from figshare; see `DATASETS.md`).
