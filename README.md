# PigeonLearningDynamics

Homing-pigeon route-learning analysis across two GPS datasets.

## Repository layout

```
papers/   reference papers (PDFs)        — see papers/README.md
data/     datasets + download pointers   — see data/README.md
```

- **`main`** branch (this one): the shared **papers + data deposit**.
- **`hv`** branch: analysis code and the interactive viewers
  (`bird_route_development.html` 2D, `flight_paths_3d.html` 3D) — route-development
  tracks, population heatmaps, basemaps, and weather / cloud / sun / geomagnetic overlays.

## Datasets at a glance
1. **Flack et al. (2014)** — multi-route homing (included in `data/`, ~22 MB).
2. **Valentini et al. (2021)** — collective exploration (1.1 GB; download from
   figshare, see `data/README.md`).
